# VLC Media Player Extension: Change Speed and Pitch

A lightweight extension for VLC Media Player that allows you to easily adjust both playback speed and audio pitch.

## 🚀 Features
* Dynamic control of playback speed.
* Accurate audio pitch shifting.
* Fully autonomous Lua-based script.

## 🛠️ Installation

### Option 1: Automatic Installation (via VLC)
1. Open VLC Media Player.
2. Go to **Tools** > **Plugins and extensions** > **Find more addons online**.
3. Search for `Change Speed and Pitch` and click **Install**.

### Option 2: Semi-Automatic (Windows only)
1. Download and extract the `.zip` archive.
2. Double-click the `install.bat` file included in the package. It will automatically copy the script into your VLC directory.
3. Restart VLC.

### Option 3: Manual Installation
If the automatic installation fails, copy the `.lua` file manually to your VLC extensions folder:

* **Windows:** `%appdata%\vlc\lua\extensions\`
* **macOS:** `~/Library/Preferences/VLC/lua/extensions/`
* **Linux:** `~/.config/vlc/lua/extensions/`

*Note: If the `lua` or `extensions` folders do not exist, simply create them.*

## 📖 How to Use
After installation, restart VLC Media Player. You can find and launch the extension in the top menu under **View** > **Change Speed and Pitch**.

---

## 🇨🇿 Instalace a použití (Česky)

### Automatická instalace přes přiložený skript (Windows)
1. Rozbalte stažený `.zip` soubor.
2. Spusťte soubor `install.bat`, který automaticky zkopíruje doplněk do správné složky.
3. Restartujte VLC přehrávač.

### Ruční instalace
Zkopírujte soubor `.lua` do složky: `%appdata%\vlc\lua\extensions\` (pokud složky neexistují, vytvořte je).

Doplněk následně spustíte v horním menu VLC přes **Zobrazit** > **Change Speed and Pitch**.
